คู่มือสำหรับอาจารย์

1. ระบบทำงานอย่างไร

อาจารย์เริ่มคาบเรียนแล้วแสดง QR code บนจอในห้องเรียน นักศึกษาสแกนด้วยกล้องโทรศัพท์และเข้าสู่ระบบด้วยบัญชีของมหาวิทยาลัย ระบบบันทึกชื่อ อีเมล และเวลาของนักศึกษาแต่ละคน และแสดงบนจอของอาจารย์ทันที

QR code เปลี่ยนทุก {{ st.qr_interval }} วินาที ถ้าถ่ายรูปโค้ดส่งให้เพื่อนที่อยู่นอกห้อง โค้ดนั้นจะใช้ไม่ได้ในเวลาไม่นาน และนักศึกษาไม่สามารถพิมพ์อีเมลของคนอื่นแทนได้

2. การเข้าสู่ระบบ

  • คลิก เข้าสู่ระบบ แล้วเลือก เข้าสู่ระบบด้วย Google {% if domains %}ใช้บัญชี {{ domains }} เท่านั้น บัญชีอื่นจะเข้าไม่ได้{% endif %}
  • ถ้าผู้ดูแลระบบเพิ่มอีเมลของคุณเป็นอาจารย์แล้ว จะเห็นหน้าหลักของอาจารย์ ถ้ายังไม่ได้เพิ่ม จะเห็นหน้าของนักศึกษา ให้ติดต่อผู้ดูแลระบบให้เพิ่มชื่อ แล้วโหลดหน้าใหม่
  • เปลี่ยนภาษาได้ระหว่าง English และ ไทย ที่มุมบนของทุกหน้า

3. การเชื่อมต่อ Gmail

คลิก เชื่อมต่อ Gmail ที่หน้าหลักหนึ่งครั้ง แล้วอนุญาตให้ส่งอีเมล หลังจากนั้นอีเมลยืนยันการเช็คชื่อถึงนักศึกษา และรายงานการเข้าเรียนจะส่งจากอีเมลของอาจารย์เอง ยกเลิกการเชื่อมต่อได้ทุกเมื่อ (ขั้นตอนนี้จะแสดงเฉพาะเมื่อเซิร์ฟเวอร์ตั้งค่าให้ส่งอีเมลผ่าน Gmail)

4. การเริ่มคาบเรียน

  1. ชื่อวิชา ไม่บังคับ ระบบจะแนะนำชื่อที่เคยใช้ระหว่างพิมพ์
  2. จำนวนครั้งเช็คชื่อระหว่างคาบ (0–3 ครั้ง) เพิ่มได้อีกระหว่างสอน
  3. เช็คชื่อออกเมื่อจบคาบ เพิ่มการเช็คชื่อครั้งสุดท้าย (เพิ่มภายหลังได้)
  4. ส่งอีเมลยืนยันให้นักศึกษาแต่ละคน และ ส่งรายชื่อผู้เข้าเรียนให้ฉันทางอีเมลเมื่อปิดคาบ
  5. คลิก เริ่มและแสดง QR code ระบบเปิดเช็คชื่อเข้าเรียนทันที

5. หน้าแสดง QR code

  • เปิดหน้านี้บนโปรเจกเตอร์ ใช้ปุ่ม เต็มจอ หรือกด F
  • แถบใต้โค้ดแสดงเวลาก่อนโค้ดจะเปลี่ยน โค้ดที่สแกนก่อนเปลี่ยนเล็กน้อยยังใช้ได้
  • รายชื่อด้านขวาแสดงผู้ที่เช็คชื่อแล้ว คนล่าสุดอยู่บนสุด พร้อมจำนวนตัวใหญ่
  • หยุดชั่วคราว (หรือกด Space) หยุดการเช็คชื่อทันที โค้ดจะถูกซ่อนและการสแกนจะถูกปฏิเสธ กด เปิดต่อ เพื่อเริ่มอีกครั้ง
  • จุดสีมุมขวาล่างเป็นสีเขียวเมื่อหน้าจอเชื่อมต่อสดอยู่ ถ้าเป็นสีแดง ระบบจะเชื่อมต่อใหม่เอง การโหลดหน้าใหม่ทำได้เสมอโดยไม่มีข้อมูลหาย
  • รายชื่อ เปิดรายชื่อผู้เข้าเรียนในแท็บใหม่

6. เช็คชื่อระหว่างคาบและเช็คชื่อออก

  • ปุ่มด้านบนของหน้าแสดงผลคือการเช็คชื่อทั้งหมดในคาบ พร้อมจำนวนคนในแต่ละครั้ง
  • คลิกการเช็คชื่อที่ยังไม่เริ่ม (หรือที่ปิดแล้ว) เพื่อเปิด การเปิดครั้งใหม่จะปิดครั้งก่อนหน้า จึงมีการเช็คชื่อเปิดอยู่ได้ครั้งละหนึ่งรายการ
  • + เช็คชื่อระหว่างคาบ และ + เช็คชื่อออก เพิ่มการเช็คชื่อใหม่และเปิดทันที เช็คชื่อออกจะอยู่ท้ายสุดเสมอ
  • นักศึกษาสแกนจอเดิมซ้ำทุกครั้ง

7. การปิดคาบเรียน

คลิก ปิดคาบเรียน เมื่อจบคาบ นักศึกษาจะเช็คชื่อไม่ได้อีก ถ้าเลือกไว้ ระบบจะส่งรายชื่อผู้เข้าเรียนเป็นตารางในเนื้อหาอีเมล คัดลอกไปวางในสเปรดชีตหรือให้ AI อ่านต่อได้สะดวก แล้วพาไปที่หน้ารายชื่อผู้เข้าเรียน

8. รายชื่อผู้เข้าเรียนและการแก้ไข

  • เปิดคาบเรียนจากหน้าหลักเพื่อดูรายชื่อ หนึ่งแถวต่อนักศึกษาหนึ่งคน พร้อมเวลาของแต่ละการเช็คชื่อ ขีดสีแดงหมายถึงพลาดการเช็คชื่อครั้งนั้น
  • ดาวน์โหลด CSV เปิดได้ใน Excel หรือ Google Sheets (ชื่อภาษาไทยแสดงถูกต้อง) ส่งรายชื่อนี้ทางอีเมล ส่งซ้ำได้
  • แก้ไขรายชื่อ → เพิ่มเอง เพิ่มนักศึกษาที่สแกนไม่ได้ เช่น โทรศัพท์แบตหมด โดยเลือกการเช็คชื่อที่ต้องการเพิ่ม
  • ลบการเช็คชื่อ ลบรายการที่ผิดพลาด

9. การเก็บถาวรและการลบคาบเรียน

  • คลิก … ข้างคาบเรียนในหน้าหลัก
  • เก็บถาวร ซ่อนคาบเรียนจาก คาบเรียนของคุณ แต่เก็บข้อมูลไว้ครบ ดูได้ที่ เก็บถาวร และกด นำกลับจากที่เก็บถาวร เพื่อนำกลับมา การเก็บถาวรคาบที่ยังเปิดอยู่จะปิดคาบนั้นโดยไม่ส่งอีเมลรายงาน
  • ลบ ลบคาบเรียนและการเช็คชื่อทั้งหมดอย่างถาวร

10. นักศึกษาต้องทำอะไร

  1. เปิดกล้องโทรศัพท์ หันไปที่ QR code แล้วแตะลิงก์
  2. ครั้งแรกให้เข้าสู่ระบบด้วย Google{% if domains %} โดยใช้บัญชี {{ domains }}{% endif %} โทรศัพท์จะจำไว้ ครั้งต่อไปสแกนครั้งเดียวก็เช็คชื่อได้
  3. เครื่องหมายถูกสีเขียวพร้อมเวลาแสดงว่าเช็คชื่อสำเร็จ และจะมีอีเมลยืนยันตามมาถ้าอาจารย์เลือกไว้
